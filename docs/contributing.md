# Contributing

Start with the main [CONTRIBUTING guide](../CONTRIBUTING.md) at the repository root. It covers project setup, the dev workflow, project layout, coding conventions, and the pull request process end to end.

Fastest areas to make a first contribution:

1. **Test fixtures** — add an HTML form page to `fixtures/` that reproduces a real-world form pattern; it directly improves test coverage.
2. **Dictionary terms** — add missing label keywords or autocomplete tokens for a language you know to the classifier dictionary.
3. **Documentation** — fix gaps or inaccuracies in the guides under `docs/`; clarity improvements are always welcome.
